1. Binary search:-i. It is faster than linear search
		  ii. Half of the remaining element can be eliminated at a time , instead of eliminating them one by   
 		  one
		  iii. Binary search only works for sorted array

2.Ex:-searching for 12
    [2,4,5,9,11,13,14,15,19,20,22,23,27,30,32,39]
   [2,4,5,9,11,13,14,15,19,20,22,23,27,30,32,39] /mid value is 8=16/2/it will compare with searching value which is                              		      ^							12
    [2,4,5,9,11,13,14]//as value is not equal to 12 i.e 15=12 false it will search further 
           ^
   [11,13,14] //now it will perform same searching and compare mid value to searching value 
       ^
    [11]//as value is not equal to 12 it will return output as "Not found"
